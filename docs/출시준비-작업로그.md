## 5. 게시 게이트를 다시 여는 절차

관리자 세션 Bearer로만. SHA를 화면에 입력하지 않는다.

1. Vercel Production `SELLERPILOT_RELEASE_SHA` = 라이브 커밋 40자
2. **그 SHA의 새 배포**가 Ready인지 확인. 옛 배포 Redeploy 금지
3. 채널 연결 · 상태 → 채널 연결 설정 → `운영 일정 재검증·재시작`
4. SHA가 보이면 채널 8개 `확인 기록` + `재조회기 확인 기록`
5. `게시 게이트 열기` (조건: attested === activeRuntime === current, queued 0, reconciliation_required 0)
6. 화면이 **8개 채널 게시 허용**인지 확인

채널 키: `qoo10` `shopee` `lazada` `coupang` `elevenst` `smartstore` `ebay` `temu`

Lazada fenced `reconciliation_required` 행은 raw SQL로 지우지 않는다. 게이트가 안 열리면 이 로그의 “남은 막힘”에 적고 중단한다.

#### 목표를 카테고리 확정으로 둔 이유
- 사용자가 막힘을 **한 개씩** 풀라고 했고, 당시 등록 사전조건의 첫 빈칸이 채널 공식 카테고리였다.
- 원장·이미지·가격은 이미 있었다. 원격 write를 성공이라고 말하려면 그 전에 말단 카테고리+공식 속성 검증이 저장돼 있어야 한다. 화면 게이트(`disabled={!verifiedLeaf || requiredFilled !== requiredCount}`)가 그 계약이다.
- 원격 listing.create/update를 이 세션에서 안 한 이유: 게시 게이트가 `2fde5da`에서 닫혀 있었고, Qoo10은 identity blocked, Shopee는 카테고리 저장이 끝난 직후였다. write/readback 없이 업로드 성공이라고 쓰지 말라는 기존 규칙.

#### Static IP를 사지 않고 Mac 워커를 쓴 이유
- 사용자 재확인: 유료 Vercel Static IP 구매 금지. 이미 화이트리스트된 Mac IP `112.172.127.206`이 있다.
- 실측: Shopee `get_category`는 Mac에서 HTTP 200, Vercel 송신 IP는 회전하며 `source_ip_undeclared` (관측 `54.116.35.135` 다음 `3.39.244.7`).
- 코드 의도(`0f7c165` / `20260904195000`): oauth.exchange와 카테고리 트리는 서버리스 드레인에서 빼고 로컬 게이트웨이가 돌리게 한다. 그래서 카테고리/연결검사는 Mac `--once`로 실행했다.

#### 11820을 고친 이유 (서버리스 드레인을 연 게 아닌 이유)
- claim 경로 실측: 로컬 워커는 `11820`, 드레인은 `204000`. 183000이 로컬 claim이 아니다.
- 카테고리를 드레인에 다시 태우면 Vercel IP로 `get_attribute_tree`가 나가 `source_ip_undeclared`가 재발한다. 그래서 드레인 쪽 예외를 넓히지 않고 로컬 11820이 집게 했다.
- 204의 결정적 근거: `serverless_gateway_job_allowed('shopee','categories.attributes')` = true 이고, 활성 `scope=serverless_cs` 토큰이 있었다. 11820 `AND NOT (… OR (allowed AND exists serverless_cs))`이면 허용 작업이 전부 로컬에서 빠진다. 토큰 길이/버전은 정상이었고(`spw_…` 47자, `sellerpilot-cli-worker/1.60`) 직접 `11820()`도 null → 인증 문제가 아니라 WHERE 문제.
- `and not`을 `and`로 뒤집지 않은 이유: 그렇게 하면 쿠팡/이베이 `orders.list`까지 로컬이 집어먹고, 실행 없이 fail-complete하면 동기화가 죽는다. 이미 한 번 그렇게 사고 냈다.
- `serverless_cs exists`만 `false and`로 죽인 이유: 그 한 줄이 204의 필요충분조건이었고, coupang in-list 제외는 서버리스가 가져가야 할 자리를 로컬이 훔치지 않기 위함이다.

#### 연결 검사를 카테고리 저장보다 먼저 돌린 이유
- `app/api/operations/snapshot/route.ts`: `last_check_status === "passed"`여야 `credentialStatus=active`. 아니면 selectedChannels에서 탈락해 Shopee 카드가 안 보인다.
