# 상품 카테고리 25장 실이미지 검수

기준일: 2026-08-17
범위: 컵·의류·뷰티·가방·신발 5개 대표군 × 5장 = 25장

## 판정

- 웹에서 확보한 실물 사진 25장은 모두 JPEG이고 가로·세로가 각각 600px 이상이다.
- SHA-256 기준 중복 이미지는 0장이다.
- ChatGPT 계정으로 인증한 Codex CLI `gpt-5.6-sol`에 각 이미지를 직접 입력해 25/25장을 기대 대표군으로 인식했다.
- 인식 신뢰도는 최소 0.88, 평균 0.9812였다.
- 최초 뷰티 후보 1장은 비누와 형태가 유사한 의료용 실리콘 제품으로 판정되어 즉시 제외했고, Wikimedia Commons의 Public Domain 비누 사진으로 교체한 뒤 재검수했다.
- 사진은 인식 회귀 검수용이다. 판매 재고·제조사·원산지·규격을 증명하지 않으므로 외부 채널의 공개 판매상품으로 자동 승격하지 않는다.

Qoo10 카테고리 값은 운영 QAPI `CommonInfoLookup.GetCatagoryListAll` 응답 3,264건에서 직접 확인했다. 분류 정규화 테스트에는 무관 카테고리 차단, 티셔츠, 비누, 크림, 토트백, 신발의 정확한 leaf 선택을 포함한다.

## 이미지 규격 범위

- 최소 원본: 768×1024
- 최대 원본: 3000×4000
- 업로드 전환 규격: 1200×1200 JPEG, 흰색 배경, contain, 48px 안전 여백, 3MB 이하
- 대표사진 1장은 필수이며 분석 사진은 상품당 최대 100장, 동시 처리 대기열은 최대 8개 상품이다.
