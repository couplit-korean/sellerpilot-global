# 채널별 CS 인증값 대조 · 2026-09-07

활성 키는7/8채널이다. **7/8은 CS 완성률87.5%가 아니다.** 실제 수신→저장→웹 표시→답변→원격 확인을 모두 입증한 채널은 아직 없다. Shopee 상품 후기는 로컬 코드·DB 원장 단계까지 올라왔지만, 운영 적용과 공급자 readback 전에는 외부 연결 완료로 계산하지 않는다. 입력칸을 더 채우는 것만으로 해결되지 않는 권한·제공자 신원·실행 경로·미구현 기능을 구분한다.

운영 웹사이트의 sample은 승인 관리자다. 활성 eBay 키의 최초 등록자가 다른 이유로 목록이 비는 것은 공용 운영 공간 조회 회귀이며, JEONGHUN Chrome 로그인 오류가 아니다. CS14는 기존 승인 관리자 공유 계약을 복구하는 로컬 수정이고 아직 운영 적용하지 않았다.

증거: 로컬 비공개 진단 파일 `.local/cs-rollout-20260907/cs-credential-presence.sql` 및 결과 JSON, `cs-reply-routing-state.sql/json`, `ebay-message-access-result.json`, `shared-cs-preflight.sql/json`. 로컬 진단은 원격 저장소에 넣지 않는다. 후속 상태는 [CS 구현 진행](./CS-구현진행-20260907.md)과 [답변 실행 경로 분석](./CS-답변실행경로-고정작업자-분석-20260907.md)을 함께 확인한다.
