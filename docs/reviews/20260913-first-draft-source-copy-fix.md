# 1차 이미지가 원본 사진으로 남던 오류 — 2026-09-13

## 재현과 원인

최신 나랑드사이다 조사 작업의 1차 이미지 요청은 3회 실패한 뒤 queued 상태로 남았고 검증 자산은 0개였다. 조사 자체의 succeeded와 1차 이미지 생성 완료는 다른 상태다. 직전 파일 해시·카테고리 테스트 확인은 이 작업의 이미지 생성 성공을 증명하지 않았다.

Mac Vision OCR은 `나랑드사이다 제로`를 읽었지만 상품명과 브랜드명이 모두 `나랑드사이다`여서 기존 상품명 정규화가 모든 상품 토큰을 제거했다. 상품 일치 검사가 실패하여 생성 단계에 도달하지 못했다. 정규화 수정 후에는 단일 병 전체 후보가 점수 7.8196으로 기존 기준 8보다 낮아 거절되는 두 번째 문제를 재현했다.

## 수정

- 브랜드/제조사 중복 제거로 상품명 토큰이 모두 사라지는 경우 실제 상품명을 유지한다. 별도 변형명 토큰이 있으면 그 토큰을 계속 요구하며 용량/수량만으로 상품을 인정하지 않는다.
- 전체 상품 후보 점수에 실제 상품 식별 일치 근거를 반영한다. 최소 점수·형상·전면 상품 일치 검사를 낮추지 않는다.
- 브라우저 생성 목록에는 `segmented-source-composite` 검수 계보와 유효한 해시가 있는 이미지만 표시한다. 원본 규격 변환본은 생성 이미지로 표시하지 않는다. 표시 가능한 이미지 없이 계보만 있는 경우 완료 수를 올리지 않는다.
- DB 복구 응답에 소유자 범위의 생성 시도/종료 상태를 추가한다. 시도 소진은 화면에서 실패로 종료하고 enqueue는 409를 반환한다. 내부 오류 원문은 브라우저에 노출하지 않는다.
- 누적 시도는 보존한다. 기본 예산은 3회이며 일반 enqueue가 늘리지 않는다. 운영자가 명시적으로 늘리는 경우 최대 6회로 제한한다.

## 적용·검증

- 실제 사용자가 올린 사진으로 전면·병 전체 분리가 통과했다. 전체 병 출력에서 뚜껑부터 바닥까지와 라벨 보존을 직접 확인했다. 같은 사진에 다른 상품명 `코카콜라`를 넣은 검사는 실패하여 잘못된 상품 수용을 막았다.
- Swift 이름 정규화 및 화면 생명주기 집중 검사 13개 통과. 렌더링 1개·DB 회귀 5개도 통과했다. 타입 검사 통과.
- migration `20260913141310_first_draft_retry_status`를 연결된 운영 프로젝트에 적용했다. journal version/name/원문 SHA-256 `95686265038c1e23921a5aec238b2e4b06045b9fe3dbdd2ff3608f0cd4b0a1d1` 일치 확인.
- 기존 Mac 실행 파일에 수정 Swift만 원자적으로 교체하고 소스 해시 일치를 확인했다. 실행 중 AI worker 재시작 없이 다음 호출부터 사용한다.
- 영향받은 최신 나랑드사이다 작업 한 건에만 max_attempts를 3에서 4로 늘렸다. attempts=3과 기존 실패 이유는 유지했다. 작업자는 4번째 시도를 수령하고 이전 실패 단계를 통과했다. 이 시점은 생성 진행 중이며 6장 저장 완료가 아니다.

다른 작업의 UI/CS 변경은 이번 수정 커밋에 포함하지 않는다. 실제 마켓 상품 등록·고객 답변을 보내는 검사는 수행하지 않는다.
