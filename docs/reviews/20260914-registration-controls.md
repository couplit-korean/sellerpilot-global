# 상품 등록 기록 정리와 대기·진행 작업 제어

2026-09-14 사용자 요청 범위: 기존 등록 시도 기록 정리, 대기 화면의 추가 상품/이전 화면 선택, 진행·대기 작업 중지와 삭제.

## 적용 내용

- 관리 중인 소유자의 등록 카드 24개를 정리했다. 상품/AI 작업 식별자 25개에 삭제·중지 상태를 남겼으며 목록 0개, 대기/실행 AI 0개, 1차 이미지 큐 0개를 DB에서 확인했다. 정리 시각은 `2026-09-13T16:57:50.090196Z`이다.
- 원격 판매채널의 상품과 성공/결과 불명확 응답 기록은 유지한다. 이번 삭제는 등록 진행 이력에서의 삭제다. 이미 실행 중인 채널 요청은 응답을 보존하며, 미전송 큐와 후속 실행을 중단한다.
- 대기 화면 내부에서 추가 상품 등록, 이전 화면, 진행상황, 중지, 삭제를 선택한다. 접수 중에는 서버 작업 ID가 확정될 때까지 이동/취소를 잠시 막는다. 다른 상품 추가는 현재 폼을 비우고, 기존 서버 작업은 진행 목록에서 계속 관리한다.
- 상품정보/1차 이미지 작업도 등록 목록에 나타난다. 완료된 1차 작업은 결과를 이어서 확인할 수 있다. 상세 작업 성공/실패가 확정되면 대기 화면을 해제한다.
- 1차 이미지 작업자는 5초마다 현재 작업의 취소 상태를 조회한다. 취소가 확인되면 생성 프로세스에 AbortSignal을 전달하고, 업로드/실패 재접수를 중단한다. 조회 실패를 취소로 오인하지 않는다.
- 새 브라우저 화면은 서버 기록 정리 시각을 확인한 후 옛 입력·연구·스튜디오 임시 기록을 한 번만 비운다. 새로 입력한 상품과 인증/다른 기능의 저장값을 보존한다.
