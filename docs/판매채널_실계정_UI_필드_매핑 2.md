# 판매채널 실계정 UI·API 준비도 매핑

기준일: 2026-08-16

대상: Qoo10 QSM, Shopee Open Platform, Lazada Open Platform

검수 방식: 사용자가 열어 준 로그인 세션에서 읽기 전용 확인

## 보안·검수 원칙

- 앱 키, 앱 시크릿, 파트너 키, 파트너 ID, 판매자 ID, IP 주소, 이메일은 문서와 소스에 기록하지 않는다.
- 콘솔 로그인 성공은 API 연결 성공으로 계산하지 않는다.
- 설정 저장, 앱 키 재발급, 판매자 추가/삭제, 상품 등록/수정, 테스트 주문 생성은 수행하지 않았다.
- API 완료는 승인된 테스트상품 1건의 `생성 → 조회 → 수정 → 판매중지`와 주문/웹훅 중복방지 증거가 모두 있어야 인정한다.

## 결론

| 채널 | 확인된 상태 | 운영 연결 차단 요인 | 현재 판정 |
|---|---|---|---|
| Qoo10 | QSM 실계정, 상품 목록, 개별 상품등록 전체 필드 | QAPI 자격증명·카테고리 조회·쓰기 PoC 미검증 | UI 매핑 완료 / API 미연결 |
| Shopee | Seller In House 앱 Online, 민감정보 접근, Sandbox v2 도구 | 운영 리다이렉트·콜백 미구성, Live Push OFF, 파트너 키 만료 대응 | 개발자 앱 준비 / OAuth·Push 미완료 |
| Lazada | Seller In-house 앱 Online, 주요 API 권한 Active, 5개 국가 판매자 허용 | 운영 OAuth 콜백·IP 허용목록·Push Mechanism 미구성 | 권한 준비 / OAuth·Webhook 미완료 |

세 채널 모두 SellerPilot 서버에서 API E2E를 통과한 상태는 아니다. 따라서 기존 화면의 “실시간”, “정상 연동” 표현은 운영 증거로 사용할 수 없으며, 샘플 매출·주문·재고 데이터와 실제 연동 상태를 계속 분리한다.

## 1. Qoo10 QSM 실제 상품등록 필드

### 계정·상품 현황

- 상품 8개
- 판매중 7개
- 재고주의 1개
- 판매종료 1개
- 상품 목록 검색 기준: 상품명, 상품코드, 판매자 SKU, 브랜드, 배송비 코드
- 상품정보와 가격·재고 다운로드 기능 확인

위 수치는 2026-08-16 화면 확인 시점의 운영 데이터이며, SellerPilot DB에 수집된 값이 아니다.

### 필수 상품 구조

1. 카테고리·브랜드
   - 대·중·소 카테고리 선택과 카테고리 검색
   - 브랜드 검색/코드, 브랜드 없음, 브랜드 신청
2. 상품 식별
   - 상품명: 최대 100자
   - 홍보문구: 최대 20자
   - 판매자 상품코드: 최대 100자
3. 판매 정보
   - 상시/기간 판매, 종료일
   - 판매가 JPY, 참고가, 재고
   - Q-재고 연결, 구매제한, 할인, Q포인트
4. 이미지·동영상
   - 대표 이미지: 정확히 1장 필수
   - 권장 800×800, 최소 600×600
   - JPG/PNG/GIF, 파일 또는 URL 업로드
   - 추가 이미지: 최대 50장, 순서변경 지원
   - 동영상: 최대 1개, MP4 50MB 이하
5. 옵션
   - 선택옵션, 추가구성, 텍스트옵션
   - 옵션 이미지와 추가구성 이미지
6. 상세 설명
   - 리치텍스트/HTML 소스, 파일/URL 이미지
   - 상세 텍스트 최대 1MB, 이미지 합계 40MB
   - 권장 너비 820px, 이미지 한 장 1MB 이하
   - 머리말·꼬리말 각각 소스 2,500자
7. 배송·반품
   - 배송비 그룹/코드/방법/운송사
   - 출하지·반품지, 반품비·반품방법, 옵션 배송비
   - 일반/당일/예약 출고
   - 결제일 기준 1/2/3영업일 출고 SLA
8. 검색·부가정보
   - 검색 키워드 최대 10개, 브랜드 키워드 금지
   - 상태, 원산지, 중량, 재질, 모델
   - JAN/KAN/ISBN/UPC/EAN/HS 등 표준코드
   - 제조일, 유통기한, 18세 제한, A/S 정보

### SellerPilot 구현 반영

- 대표사진 1장을 내부 `primary` 역할로 강제하고 추가사진은 순서를 가진 자산으로 저장한다.
- 내부 Variant/SKU와 Qoo10 선택옵션 조합을 별도 매핑 테이블로 관리한다.
- 카테고리 선택 뒤 QAPI 필수속성을 다시 받아 등록 전에 검증한다.
- 상세페이지 원본 블록과 Qoo10용 820px 결과물을 분리 보관한다.
- 배송비 그룹, 출하지, 반품지는 상품값이 아니라 채널 계정 설정 참조로 관리한다.
- 등록 성공 뒤 원격 상품번호를 내부 상품과 연결하고 부분 성공을 숨기지 않는다.

## 2. Shopee Open Platform 준비도

### 확인된 상태

- 앱 유형: Seller In House System
- 앱 상태: Online
- 민감정보 접근: 가능
- Sandbox v2 테스트계정 도구 제공
- API Test Tool, API Access Log, Push Log, API Calls Statistics, Security Dashboard 제공
- IP 허용목록 기능 활성 상태 확인
- 파트너 키 만료 예정일: 2026-09-15

### 차단 요인

- Test/Live Redirect URL이 SellerPilot 운영 콜백이 아닌 임시 도메인이다.
- Get Live Push가 OFF다.
- Test Call Back URL이 비어 있다.
- 콜백 배포 서비스 지역을 확인하고 검증해야 한다.
- 최근 6시간 라이브 푸시 수신량과 성공률 증거가 없다.
- 키 만료 전 교체, 이중키 전환, 실패 시 롤백 절차가 없다.

### 개발 순서

1. SellerPilot 운영 OAuth 리다이렉트와 콜백 도메인 확정
2. 파트너 키를 서버 비밀 참조로 연결하고 만료 알림 추가
3. Sandbox v2 판매자 계정으로 Seller/Profile·Category 읽기 PoC
4. 글로벌 상품 생성과 SG 국가 게시를 분리한 작업 상태 모델 구현
5. 주문/상품 Push 엔드포인트에서 서명검증·중복방지·재전송 기록
6. API Access Log와 SellerPilot trace ID를 연결해 실패를 역추적

## 3. Lazada Open Platform 준비도

### 확인된 상태

- 앱: Couplit Commerce
- 앱 유형: Seller In-house APP
- 앱 상태: Online
- OAuth2.0 Server-side
- Access Token 30일, Refresh Token 180일
- 상품관리, 상품정보, 가격·재고, 물류, 주문이행, 주문정보, 카탈로그, 재무 등 주요 권한 그룹 Active
- MY·PH·SG·TH·VN 판매자 계정 5개가 허용목록에 등록

### 차단 요인

- Callback URL이 SellerPilot 운영 콜백이 아닌 임시 도메인이다.
- 작업서버 IP가 허용목록에 지정되지 않아 IP 제한 기능이 비활성이다.
- Push Mechanism Callback URL이 비어 있다.
- Order, Product, System Notification, Promotion, Seller, Fulfillment 이벤트 그룹이 선택되지 않았다.
- SellerPilot 서버에서 토큰 발급·갱신과 API 호출 증거가 없다.

### 개발 순서

1. 운영 OAuth 콜백 URL 교체와 국가별 판매자 승인 흐름 검증
2. 고정 작업서버 IP 확정 후 허용목록 등록
3. Access/Refresh Token 암호화 저장과 만료 전 갱신 작업 구현
4. Category·Brand·Product 읽기 PoC
5. 이미지 마이그레이션/업로드 → 상품 생성 → 가격재고 반영 PoC
6. Order·Product·Fulfillment Push 서명검증과 누락 보정조회 구현
7. 국가별 원격 상품/옵션/창고 ID를 내부 SKU와 연결

## 4. 공통 5단계 운영 게이트

| Gate | 통과 조건 | 필요한 증거 |
|---|---|---|
| 01 자격증명 | 키·토큰을 서버 비밀 참조로만 연결 | 화면/로그 마스킹, 권한 최소화, 만료일 확인 |
| 02 읽기 PoC | 판매자·카테고리·상품 1건 조회 | 요청 ID, 원문 응답, 정규화 결과, 재시도 기록 |
| 03 쓰기 PoC | 테스트상품 생성·조회·수정·중지 | 원격 상품/옵션 ID, 전후 상태, 부분실패 기록 |
| 04 주문·웹훅 | 주문 수집·중복제거·누락복구 | 서명검증, 이벤트 ID, 체크포인트 재시작 |
| 05 제한 운영 | 30~100 SKU 운영과 장애복구 | 호출제한, 토큰만료, 채널장애, 재고경합 결과 |

## 5. 다음 승인 필요 사항

- 채널별로 등록·수정·중지에 사용할 테스트상품 1개
- Shopee/Lazada OAuth 및 Push에 사용할 운영 HTTPS 도메인
- Lazada IP 허용목록에 넣을 고정 작업서버 IP
- Qoo10 QAPI 키 발급/보유 여부와 공식 API 호출 권한
- 파트너 키 교체를 실행할 시점과 롤백 담당자

이 다섯 항목이 확정되기 전에는 실계정 쓰기 동작을 자동화하지 않는다.
