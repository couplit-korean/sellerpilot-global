## 구현한 흐름

1. 미완성 입력도 `intake` 초안으로 서버에 저장하고 URL의 draft ID로 복원한다. 로컬 파일 자체는 서버 초안에 넣지 않으며 파일 재선택 필요를 표시한다. AI 재분석은 사람이 수정한 필드를 덮어쓰지 않는다.
2. 공통 상품 사실/가격/재고/배송 포장 중량과 채널별 예외를 분리한다. 공통 변경 후 채널별 사람이 수정한 값은 유지한다. 판매 순중량과 배송 중량은 서로 대체하지 않는다.
3. 공식 카테고리 메타를 단일·복수 선택/숫자/단위/예·아니요/반복 텍스트/조건부 필수/선택 고시·인증으로 저장·렌더링한다. 미지원 공식 항목은 숨기고 준비 완료로 만들지 않는다.
4. 채널별 자동 입력 전체 보기·필수/확인 항목 보기·검색·직접 수정 표시를 제공한다. 쿠팡 고시는 항목별 편집/추가/삭제하며 빈 배열도 정확히 저장한다. 기존 advanced JSON은 최종 검토용으로 유지한다.
5. `publish` 초안은 상품/owner/채널/국가/target/credential/category에 연결한다. CAS 충돌과 저장 결과 불확실 시 재조회 전 재저장을 막는다. 국가 변경은 전체 입력을 임시 잠그고 성공 때만 target+payload를 함께 바꾸며 실패 시 기존 값 유지, 20초 timeout을 적용한다.
6. SKU·카테고리 식별 구조 변경과 옵션 행 재정렬/삭제로 다른 상품에 값이 붙는 문제는 저장·전송 전 차단한다. 일반 고시 반복 행은 자유 편집할 수 있다.
7. 상세 승인이 오래됐더라도 owner 검증된 편집 전용 context로 입력 가능하다. **편집 가능은 송신 승인 복구가 아니다.** 기존 strict publish-context와 provider 가드는 유지한다.
8. 프로그램 전송 전에 초안 저장 결과를 확인한다. 기존 원격 상품/중복 방지 계보는 보존한다.
