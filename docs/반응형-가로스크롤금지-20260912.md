## 확인한 것 / 안 한 것

확인:

- Preview 로그인 `/` 와 `/privacy` 를 PC 1440×900에서 열었고 `scrollWidth === 1440`.
- Preview 빌드 Ready, 커밋 제목이 배포 목록에 보임.

미확인 (완료로 쓰지 말 것):

- 390 / 768 / 1024에서 대시보드·상품·등록·주문·CS·연결 등 전 view 실화면.
- Aside 브라우저는 `page.setViewportSize`가 없고 iframe `contentDocument`는 null이라 그 폭을 이 세션에서 못 재었다.

- 로그인된 운영 셸의 전 페이지 가로 스크롤 0.
