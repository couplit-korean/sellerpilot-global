## 확인한 것 / 안 한 것

확인 (Preview `d75234a`, CDP `Emulation.setDeviceMetricsOverride`, 문서 `scrollWidth` + 오른쪽 넘침 + `overflow-x: auto|scroll` 내부팬):

- 390: 운영 view 23개 + `/privacy` + 상품상세 `1ed4acfc-7603-48ec-a638-241131e59358` + 햄버거 + 통합검색 + 알림 + 계정설정. `scrollWidth === 390`, 오른쪽 넘침 0, 내부 가로팬 0.
- 768: 운영 view 23개 + `/privacy` + 같은 상품상세. `scrollWidth === 768`, 오른쪽 넘침 0, 내부 가로팬 0.
- 1440: overview·등록·주문·CS. `scrollWidth === 1440`.
- 표는 `display:block` 카드화, 데스크톱 표가 가로로 남는 화면은 안 보임.
- 상단 `관`은 아바타 한 글자(잘린 라벨 아님). 스크린샷의 원형 FAB는 앱 DOM 고정 요소가 아님.

미확인 (완료로 쓰지 말 것):

- 1024: 연속 이동 중 Preview가 `403 This request was blocked`라 무효.
- Puck 상세 편집기 실화면: 상품상세 스튜디오 결과가 `불러오는 중`에 머물러 버튼을 못 열었고, 이후 Preview 403.
- Production 화면.
- `tests/fold-upload-overlap.browser.mjs`는 이 샌드박스에서 Chromium SIGABRT.

알려진 잔여 충돌(시트 규약):

- `mobile-optimization.css`의 주문 원장 sticky+가로팬 vs `responsive-fit.css` ≤1180 카드화. 390 실측에서 주문 표 `scrollWidth === clientWidth`.
- Puck 에디터 내부 캔버스 스크롤은 페이지 팬과 별개. 실화면 미측정.
