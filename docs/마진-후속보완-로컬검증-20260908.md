## 변경

- 상품 변경 시 원가, 시장 참고가, 채널별 배송·3PL·통관비 및 수수료를 초기화한다. KRW 상품은 새 기준 판매가를 적용하고 외화 상품은 이전 원화 판매가를 남기지 않는다.
- 실시간 환율은 5분, 일일 대체값의 기준일은 4일 이내여야 한다. 두 유형 모두 수신 후 5분까지만 유효하다. 잘못된 시각·미래 시각·누락 증거를 거절하고 UI와 저장 검증에 같은 정책을 적용한다.
- 환율이 없거나 만료되면 해외 채널의 이익·마진·시장 비교 결과를 비우고 목표 충족 배지를 표시하지 않는다. 국내 채널은 계속 사용할 수 있다.
- 저장·삭제 전체 요청(로그인 확인과 응답 본문 포함)을 15초로 제한한다. 전송 이후 응답 불확실·5xx·저장 ID 누락은 자동 재전송하지 않고 이력을 재조회한다. 추가 쓰기는 잠그고 이력 확인 후 화면을 다시 열도록 안내한다.

## 검증 경계

브라우저 테스트는 실제 컴포넌트를 사용하지만 인증·환율·저장 API는 로컬 fixture로 대체한다. 운영 DB 쓰기와 실제 마켓 검색·등록은 수행하지 않았다. 수수료·배송비는 입력 기반 예상값이며 판매자 계약 운임의 자동 조회를 의미하지 않는다. 환율 저장 검증은 시각 유효성과 환산 일관성 검증이며, 외부 공급자 서명 증명을 추가한 것은 아니다.
