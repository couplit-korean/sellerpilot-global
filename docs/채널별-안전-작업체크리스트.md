## 공통 작업 규칙

- 운영 화면과 운영 DB를 사실 기준으로 사용한다.
- 확인하지 않은 값을 발명하지 않는다.
- 원격 쓰기 전에는 정확한 상품·계정·마켓·remote ID·payload·중복 방지 조건을 확인한다.
- `reconciliation_required` 작업은 취소·재실행·상태 변경하지 않는다.
- 비밀번호·토큰·API 키를 출력하거나 문서에 기록하지 않는다.
- 유료 Static IP를 구매하거나 제안하지 않는다.

- 코드 수정이 필요하면 해당 채널 전용 파일 또는 명확히 분리된 새 파일만 제안한다. 공용 파일 수정은 실제 변경 전에 영향 범위를 보고한다.

## 채널별 보고 형식

각 에이전트는 아래 형식만 사용한다.

1. `확인 완료`: 운영 화면/DB/코드에서 직접 확인한 사실
2. `미확인`: 접근하지 못했거나 증거가 부족한 항목
3. `안전하게 실행 가능`: 지금 실행해도 중복·계정·정책 위험이 없는 작업
4. `차단`: 외부 조치 또는 사용자 확인이 필요한 작업
5. `변경 파일/상태`: 실제 변경이 있을 때만 나열
6. `다음 한 단계`: 체크리스트 안에서 가장 작은 다음 작업
