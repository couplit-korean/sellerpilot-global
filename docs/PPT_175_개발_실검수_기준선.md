### 1. 데이터·보안

- Couplit Supabase 계정에 마이그레이션 실적용·관리자 승인·MFA 강제
- 개인정보 마스킹·보존기간·접근 감사
- 상품·가격·재고·주문의 변경 이력과 원본 이벤트 보관

### 2. 채널 연결

- 상품 등록 센터의 공통 상품을 채널별 공식 payload로 변환해 실행 API에 연결

- 11번가 로그인 전용 판매자 명세의 운영 URL·서비스 코드·상태 코드표 확정
- 호출제한 지수 백오프, 부분 성공 보상, 실패 대기열과 수동 재처리
- 카테고리·브랜드·필수속성의 주기 동기화

### 3. 운영 코어

- 중앙 재고원장, 예약·확정·취소·반품 트랜잭션
- 웹훅 중복 제거와 누락 보정조회
- 작업 큐, 스케줄러, 워치독, 지수 백오프와 회로차단
- 안전재고·자동품절·세트 구성품 연동차감
- 정산 예정액과 실제 입금의 차이 대조

### 4. 품질·규제

- 흐림·반사·노출·잘림·중복 이미지 검사
- 바코드·OCR·공급사·내부 이미지 후보의 신뢰도 기반 매칭
- 국가×카테고리 규칙표, 금지품목·금지표현·인증 확인
- 사실정보 잠금, 라벨 변조·워터마크·저작권 검사
- 국가별 번역 용어집과 채널별 글자수·금칙어 검증

### 5. 검수

- 실제 상품 1건 촬영→판정→콘텐츠→마진→Qoo10·Lazada 등록 E2E
- timeout·429·5xx·중복 웹훅·부분 성공 복구
- 10,000건 동시 주문과 재고 음수 방지
