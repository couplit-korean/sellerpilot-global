# Shopee 공통 정규화 연결 — 2026-09-08 10:54 UTC

공통 소유 lib/channels/inquiry-sync.ts의 normalizeShopeeReturn에 제출된 projectShopeeReturnDetail 및 shopeeReturnDetailRevision을 연결했다. providerContext.returnDetail/detailRevision으로 기존 필드와 함께 보존하고, 변경 식별자 계산에도 상세 digest를 포함했다. 기존 replySupported=false/빈 replyContext 유지. 운영 변경 없음.

회귀 검증: 전체 선택 묶음 124개 중 기존 123개 통과. 신규 fixture가 기존 필수 media 배열을 생략하여 1개 실패했고, fixture에 빈 image/buyer_videos 배열을 명시한 뒤 관련 30/30 통과. 소스 변경 없이 fixture만 교정했으므로 다른 이미 통과한 시험은 재실행하지 않았다. 수정 파일 ESLint 통과. 로그 /tmp/cs-coordinator-shopee-normalizer.tap 및 /tmp/cs-coordinator-shopee-normalizer-focused.tap.

새 시험은 재평가 사유/금액 변경의 식별자 변화, 동일 응답 재실행 식별자 유지, 연락처/주소 가지 제외 및 답변 금지를 확인한다.

운영 적용 주의: 상세 digest가 새로 포함되어 이전 알고리즘으로 저장한 revision과 다르다. 기존 원장이 있는 경우 재수집 전후 메시지 대조/reconciliation이 필요하다. 운영 DB에는 적용하지 않았으며, 단순히 중복 0으로 보고하지 않는다. 첨부 원문 retention 및 history DB/UI 연결도 미완료.

다음 단일 행동: 최신 completion wrapper의 Shopee continuation 격리 DB replay. 아직 이 검증을 완료하지 않았으므로 gateway 부분 수정 전체 종료로 표시하지 않는다. 새 작업 상태 cursor는 이번 실행에서 갱신하지 않았다.
