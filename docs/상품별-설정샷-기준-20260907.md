# 상품별 설정샷 기준 — 2026-09-07

식품=주방처럼 대분류만으로 장소를 정하지 않는다. 상품명에 나타난 세부 형태와 용도를 우선하고, 제공된 상품 카테고리와 채널 카테고리 명칭·경로를 보조로 사용한다. 포장지 원재료의 단어는 상품의 정체성을 바꾸는 근거가 아니다.

## 선택과 생성 경로

`resolveProductSettingShot`이 공통 프로필을 선택해 CLI와 서버 배경 생성에 전달한다. 마스터 상세 기획에도 같은 프로필 지침을 넣는다. 기본은 제품 중심 사진 세트 6개, 관련 준비 맥락 2개이며, 상품군이 불명확하면 8개 모두 중립 제품 사진 세트다. 슬롯마다 방·재질·브랜드 색을 바꾸도록 강제하지 않는다. 정보 목적과 구도로 구분하며 원본 동일성과 중복 검수는 유지한다.

상품명의 구체적인 단서가 채널 카테고리보다 우선한다. 동급 카테고리가 충돌하면 중립 프로필을 선택하고 충돌 이유를 남긴다. 제조·영양·소비자상담 등 정보 표시가 중심인 측면은 설정샷 주제로 사용하지 않고 근거 영역에만 쓴다.

## 채널별 연결 범위

채널의 공식 등록 카테고리 ID를 새로 만들거나 수정하지 않는다. 다음은 조회되거나 입력된 **명칭·경로**를 해석하는 범위이며 공식 최신 카테고리 트리 전체를 수집한 결과가 아니다.

| 채널 | 사용할 단서 | 연결 방식 |
|---|---|---|
| Qoo10 | 일본어·한국어·영어 세부명 | 美容液 → 세럼, ゼリースティック → 젤리스틱 |
| Shopee | 국가별 카테고리의 지원 언어 명칭 | Serums → 세럼, Pet Food → 반려동물 식품 |
| Lazada | 국가별 카테고리의 지원 언어 명칭 | Phone Cases → 휴대폰 액세서리 |
| 쿠팡 | 한글 상품군·세부명 | 즉석밥 → 즉석식품, 조미료 → 소스·조미료 |
| 11번가 | 한글 상품군·세부명 | 티백 → 차, 원두 → 원두커피 |
| 스마트스토어 | 한글 카테고리 경로 | 강아지간식 → 반려동물 식품 |
| eBay | 영어 명칭·경로 | Cameras & Photo → 촬영용품 |
| Temu | 지원 언어의 상품 유형 | Storage Box → 수납용품 |

현행 생성은 `product.category`와 상품명을 항상 사용한다. 호출자가 조회한 채널 명칭·경로는 선택적 `sceneCategoryHints`로 함께 전달할 수 있다. 이 변경에서 등록 DB의 카테고리를 새로 조회하거나 생성 작업에 자동 첨부하는 경로는 추가하지 않았다. 미지원 언어·숫자 ID만 있는 경우 추측하지 않고 상품명 또는 중립 연출로 돌아간다.
