## 중앙 완료 판정 보완

`sellerpilotAdditionalEvidenceRequired`가 있으면 성공한 상품 API 결과도 작업 완료 상태를 `reconciliation_required`로 전달한다. worker 쪽 판정 외에 서버 완료 경계에서도 재검사하여 오래된 worker가 보낸 낙관적 succeeded를 그대로 저장하지 않는다. provider 응답은 원본 증거로 보존하고 별도 오류 코드 `LISTING_ADDITIONAL_EVIDENCE_REQUIRED`를 남긴다.
