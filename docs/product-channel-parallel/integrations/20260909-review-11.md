## Temu r7 검토 및 보완 요청

동결 patch SHA `740c9a7ebee483cfd6707d1265d7af5136b778b92cde247d24ce03046a08e4c1`의 보고/코드를 읽고 담당 worktree의 실제 helper를 호출했다. 중앙에는 적용하지 않았다.

1. mallType=100에서 저장된 optional semi identity가 객체이고 원격 값이 배열이어도 모두 null로 바뀌어 `TEMU_ACCOUNT_IDENTITY_VERIFIED`가 반환됐다. 제공된 malformed 값을 부재와 구분하도록 r8을 요청했다.
2. nowSeconds=NaN은 구조화된 검증 실패 대신 RangeError를 던졌다. 유효 시계 검사와 회귀를 요청했다.
3. `9007199254740993` raw numeric mall ID가 Node22 JSON source reviver로 정확히 보존되는 것을 직접 확인했다. 기존 테스트의 숫자는 safe integer 범위여서 실제 큰 정수 반례도 추가하도록 요청했다.
4. 공식 문서는 중앙 web open에서 읽을 수 없었다. 담당에게 실제로 읽은 필드·만료 시간 단위·필수 여부 근거를 요청했다. 독립 공식 문서 확인 완료로 표시하지 않는다.

앱 Active 상태를 기다리기 전에 할 수 있는 서버 credential 저장 연결도 계속 배정했다. frontend identity 값을 신뢰하지 않고 fresh signed response에서 server-owned binding을 저장하며 토큰 변경 시 이전 binding이 남지 않게 하는 로컬 route/RPC 수정안이다. 공유 파일은 별도 scratch의 동결 제안으로만 제출한다.
