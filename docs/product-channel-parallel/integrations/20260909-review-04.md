## 제출 적용 관리

동결 patch SHA256과 원본 before hash를 확인했다. 다른 채널이 수정한 공통 파일은 차이를 검토해 정상 context로 재적용했고, 같은 삽입 위치에 모인 guard 및 국내채널 fixture는 채널별 변경을 보존하며 순차 반영했다. 운영 소스에 zero-context patch를 강제 덮어쓰지 않았다.

Smartstore r4가 준비 중 같은 이름으로 두 해시로 수집되어, 최종 metadata와 일치하는 a1a8e44c patch만 적용했다. 구버전 snapshot은 superseded 근거와 함께 보존한다. Git 일부 commit-tree 조회 지연 시 고정 scratch와 소유 파일의 바이트 일치 및 before/after hash를 보존한 뒤 최소 diff를 적용했다.

Lazada seller mode 공식 근거는 [GetSeller](https://open.lazada.com/apps/doc/api?path=/seller/get)와 [공식 schema JSON](https://isvconsole.lazada.com/handler/share/apidoc/getApi.json?path=%2Fseller%2Fget)에서 직접 재확인했다. marketplaceEaseMode는 optional Boolean이므로 부재 시 추정하지 않는다.
