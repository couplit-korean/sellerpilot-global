# 2026-09-09 두 번째 통합 검토

Qoo10 추가 소유 커밋 `2558ae2e6d0f0cdceca38d80e0500cf6b3e7f008`, 11번가 소유 변경 `e8d8215..284d91d445eadded6dbdbff26c132db6b1d1550b`를 원본 파일 대조 후 정본에 순차 통합했다. Qoo10 common r4의 patch 내용은 이미 적용한 r3와 SHA256이 같아 재적용하지 않았다.

11번가 common r2를 검토해 catalog 판매자 ID를 필수로 바꾸고 diagnostic에서 판매자 ID 누락/제어문자/길이 오류를 provider 호출 전에 거부했다. 문자 제어 검사는 ESLint 호환을 위해 문자 코드 검사로 구현했다. 상품 검색 성공 메시지는 계정 ID 원격 일치를 주장하지 않는다. 새 진단 회귀 2개를 추가하고 기존 공유 진단 fixture에 판매자 ID를 명시했다.

11번가 등록 후 검증은 상위 productNo와 내부 Product.prdNo를 각각 대조한다. 상품 조회의 보장 필드를 검사하고 재고는 별도 Stock GET으로 확인한다. 조회 API로 못 보는 이미지·고시·인증·일부 배송 필드는 추가 증거 필요 항목으로 반환한다. 이 플래그가 공통 원장과 UI에서도 전체 검증 완료와 구분되는지 후속 검토를 11번가 담당에게 배정했다. 아직 상품 실제 등록 또는 사용자 요구 전체 검증 완료가 아니다.

Qoo10은 실제 달력 날짜·일반 출고일 1~3일을 검사하고 등록 후 정가(RetailPrice)를 요청값과 대조한다. 기존 공통 worker의 문맥 차단은 유지한다.
