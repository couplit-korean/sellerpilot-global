## 운영 100%를 닫는 증거 순서

1. 운영 migration history의 version·name·source hash를 이번 CS 후보 migration 전체와 대조한다.
2. preview DB와 preview 배포에 migration과 앱을 적용하고 구버전/신버전 rolling compatibility를 검증한다.
3. 관리자 로그인 상태에서 archive, raw inbox, quarantine, coverage, scope health, credential binding, import, order binding, recovery 화면을 API→DB→UI 순서로 확인한다.
