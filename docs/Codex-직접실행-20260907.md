- 상품정보제공고시는 `가공식품`으로 선택했다. 공식 표시 이미지에서 읽은 제품명·식품유형 과자·생산자/소재지·측면 표기 소비기한 형식·315g(52.5g×6봉)·전체 원재료와 원산지·1봉 영양성분·알레르기/교차혼입 주의·국내제조·공식 고객센터를 각 필드에 직접 입력했다. 현재 로트의 날짜를 추정하지 않았으며 `제품 측면 표기일까지(연.월.일)`로 기록했다.
- 구비서류를 펼쳐 선택형 `기타인증서류`만 나타나고 필수 표시가 없음을 확인했다. 공식 라벨 이미지의 재배포 권리가 확인되지 않았으므로 첨부하지 않았다.
- 아직 `임시 저장`, `중간저장`, `상품등록`은 누르지 않았다. 쿠팡 외부 상품 ID와 판매/심사 상태는 아직 없다. 다음 단일 외부 동작은 최종 필수값 검토 후 사용자 실행시점 승인으로 `상품등록`을 1회 누르는 것이며, 성공 응답 뒤 판매자센터 exact SKU/GTIN과 가능한 구매자 화면을 원격 재조회한다.
