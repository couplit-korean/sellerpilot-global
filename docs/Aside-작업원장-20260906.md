## 4. 매 진행 보고 및 종료 때 확인

1. 무담당 잔여 작업, 실제 실행자 없는 RUNNING, 증거 없는 DONE을 점검한다.
2. 동일 파일·탭·채널·상품의 외부 쓰기 소유권 중복을 점검한다. P0-03/CH-SS는 한 job만 사용한다.
3. 대기 중인 요청은 결과부터 회수한다. 쿠팡 카테고리 조회·OAuth·지원 문의·상품 등록을 반복 제출하지 않는다.
4. READY 작업은 실제 통합/필요한 검증/운영 반영 증거를 충족한 범위만 DONE으로 변경한다.
5. 보호 SQL을 제외하고 필요한 파일만 선별한다. 로컬 변경을 보존한 정상 Git 통합, 통합 판본의 필요한 검증, 현재상태·운영 보고 일치를 확인한다.
6. 첫 등록 성공은 다른 담당 종료 전에 즉시 보고한다. UI 초안/queued/배포/테스트를 원격 등록 성공으로 표시하지 않는다.
