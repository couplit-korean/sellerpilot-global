# Aside 공용 작업 원장 — 누락·중복 방지

이 원장은 작업 배정과 완료 판정의 단일 기준이다. 현재 행은 인계 문서와 코드 검토에 근거한 초기 목록이며 **실제 에이전트 배정·운영 조회·새 실행 결과가 아니다.** 총괄이 시작 시 기존 실행 중인 작업과 대조하고 갱신한다.

## 1. 상태·소유권 규칙

- 상태: `TODO` 미착수, `CHECK` 기존 증거/현황 확인 필요, `RUNNING` 단독 담당 수행 중, `BLOCKED` 정확한 외부/입력 대기, `READY` 코드·준비 완료이나 운영 반영/최종 검증 전, `DONE` 완료 기준과 증거 충족.
- 행마다 `task ID / 담당 agent ID / 상태 / 소유 파일·채널·상품·탭 / 기준 SHA·승인 버전 / 완료 기준 / 증거 / 다음 행동 / 갱신 시각`을 유지한다. 긴 증거는 비공개 파일 경로로 참조한다.
- 원장은 **총괄만 수정**한다. 하위는 자기 task ID의 결과를 총괄에 전달하고 다른 담당 상태를 덮어쓰지 않는다. 담당 전환은 이전 담당의 실제 실행·외부 작업 상태를 확인한 뒤 기록한다.
- 시작 전 이미 같은 목표·상품·채널·파일을 소유한 RUNNING/READY/DONE 행이 있는지 확인한다. 같은 일을 새 ID로 만들어 중복 착수하지 않는다. 재시작 시 기존 에이전트·프로세스·job을 먼저 확인한다.
- `DONE`은 증거에 적힌 범위에서 재실행하지 않는다. 같은 소스 SHA·상품/승인 버전·계약이고 관련 변경이 없으면 기존 검증을 재사용한다. 재개가 필요하면 **변경된 입력/소스/외부 상태, 기존 증거가 불충분한 이유, 재검증 범위**를 먼저 기록하고 기존 ID를 재개한다.
- 테스트·Preview·Production·provider 요청·원격 재조회는 다른 완료 기준이다. READY를 DONE으로 바꾸려면 해당 행의 실제 기준을 충족해야 한다.
- 전체 원장을 첫 등록의 체크리스트로 실행하지 않는다. 총괄은 P0 행, 하위는 자기 배정 행부터 진행한다.

## 4. 누락·중복 방지 점검

1. **시작:** 기존 작업·에이전트·job·원격 ID와 원장을 대조한다. 상품 ID·채널·operation·승인 버전·요청 지문이 같은 작업은 한 번만 실행한다. P0 행과 CH 행은 같은 job을 참조한다.
2. **쓰는 직전:** 담당·현재 승인·필수값·기존 claim/lock·중복 원격 상품을 확인한다. 공식 멱등키와 기존 job/attempt를 보존한다. 새 키 발급으로 실패/미결 작업을 우회하지 않는다.
3. **timeout/202/응답 유실:** 실패라고 단정하거나 새 create를 보내지 않는다. 기존 job·공급자 응답·원격 상품을 조회해 `submitted` 또는 `reconciliation_required`로 관리한다.
4. **코드 검증:** 정확한 소스 SHA·파일·테스트 이름·결과를 기록한다. 이미 통과한 같은 판본은 재사용하고 변경 영향·이전 공백만 다시 검증한다. 검사 수를 다른 실행과 중복 합산하지 않는다.
5. **에이전트 종료:** 완료 기준·변경 파일·검증 로그·외부 결과·남은 조건을 전달받기 전 DONE으로 표시하지 않는다. “작업자 완료”와 “운영 반영 완료”를 분리한다.
6. **정기 확인:** 총괄은 짧은 진행 보고 시 무담당 TODO, 실제 실행자 없는 RUNNING, 증거 없는 DONE, 동일 파일/채널 중복 소유, 사용자 입력이 필요한 BLOCKED를 확인해 재배정한다. 외부 대기 담당은 독립 가능한 작업으로 옮긴다.
7. **마감:** 8채널·상세·CS·재고·주문·배송·DB·배포의 모든 행에 담당/상태/다음 행동이 있는지 확인한다. 실제 확인되지 않은 것은 CHECK/BLOCKED/READY로 남긴다. 원장과 현재상태·최종 보고를 같은 증거에 맞춘다.

## 5. 재개 기록 형식

재개할 때 기존 ID 아래에 기록한다. 새 ID로 완료 이력을 숨기지 않는다.

`시각 | task ID | 이전 상태 → 새 상태 | 변경된 소스/입력/외부 상태 | 재개 사유 | 최소 재검증 범위 | 담당 | 증거 경로`

아직 실행·배정·재개 기록 없음. 다음 실행 총괄이 실제 결과만 추가한다.
