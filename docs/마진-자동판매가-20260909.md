마진 계산 화면의 `목표 마진 판매가 자동 적용`은 기본으로 켜진다. 채널별 원가·배송비·통관 고정비와 수수료, 공통 세금·목표 마진을 반영해 판매가를 역산하고 해당 통화의 판매 단위로 올림한다. 올림한 현지 판매가를 원화로 재환산해 순이익과 마진을 다시 계산하며, 저장 요청도 같은 엔진 입력을 사용한다. 수동 판매가 검토는 체크 해제로 가능하다. 계산 결과 저장은 명시적 버튼 동작이며 마켓 상품 가격을 자동 변경하지 않는다.

원가·배송비를 확인하지 않았거나 해외 환율이 없거나 만료된 경우 기존 계산·저장 차단을 유지한다. 비용을 수정하면 확인을 다시 요구한다. 상품 변경 시 자동 모드와 기본 비율로 초기화하며 다른 상품의 비용을 가져오지 않는다.

국내·현지 배송란은 한국 내 운송비와 도착국 배송비 합계를 입력하는 항목으로 명확히 표시했다. 국제 배송에 포함된 비용은 중복 입력하지 않는다. 관세·통관·기타 고정비도 판매자 부담 주문 1건 금액으로 표시한다.
