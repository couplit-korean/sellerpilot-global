# 카테고리별 상세페이지 프롬프트

category-prompts.json은 사진 분석 결과에 따라 판매용 상세페이지 구조를 선택하기 위한 기계 판독형 프롬프트 라이브러리다.

## 공통 생성 순서

1. 촬영 이미지 OCR과 제품 영역을 분석한다.
2. 제품명, 카테고리, 포장 단위, 표시 성분, 인증, 주의사항을 확인됨 / 미확인으로 나눈다.
3. matchKeywords와 법적 제품 분류를 함께 사용해 하나의 카테고리 템플릿을 선택한다.
4. 채널 상단 영역(가격·옵션·배송)과 판매자 제작 영역(긴 세로형 상세 콘텐츠)을 분리한다.
5. sectionOrder 순서로 860px 상세 원본을 만든 뒤 모바일 한 열 레이아웃으로 변환한다.
6. 한국어 기준본을 검수한 뒤 일본어, 영어, 말레이어로 번역하되 숫자와 단위를 보존한다.
7. categoryRules와 globalRules 위반 여부를 점검하고 미확인 값은 게시 차단 대상으로 남긴다.

## 현재 데모에 선택되는 템플릿

BEYOND ORIGIN 화이트토마토 글루타치온은 포장에 당류가공품으로 표시되어 있으므로 general_food_tablet을 선택한다. 정제 형태만으로 건강기능식품이라고 분류하지 않는다.

## 플랫폼 공통 패턴

- 대표 이미지, 상품명, 가격, 옵션, 배송, 후기 모듈은 오픈마켓이 제공하는 구매 영역이다.
- 판매자가 제작하는 상세 콘텐츠는 별도의 긴 세로 영역으로 구성한다.
- 상세 콘텐츠는 첫 화면의 제품·분류 인지, 수치형 핵심 정보, 사용 또는 섭취 정보, 실물 근거, 주의사항, 상품정보 고시 순으로 읽히게 한다.
- 채널별 UI를 복제하지 않고 판매자 콘텐츠만 재사용 가능한 구조로 만든다.

## 게시 전 필수 차단 조건

- 법적 제품 분류가 미확인인 경우
- 원재료·알레르기·주의사항처럼 카테고리 필수 정보가 누락된 경우
- 인증, 시험 결과, 특허, 판매량, 후기의 출처가 없는 경우
- AI가 상품 외형, 라벨, 로고, 색상 또는 구성품을 바꾼 경우
- 번역본의 수치와 단위가 한국어 기준본과 다른 경우
